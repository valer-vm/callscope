# CallScope

Анализ записанных телефонных звонков отдела продаж: кто из менеджеров и на каком этапе скрипта теряет клиентов. Всё считается локально, записи не покидают компьютер компании.

## Язык

**Звонок**:
Один разговор менеджера с клиентом, разобранный и оценённый целиком. В панели звонок появляется из загруженной записи; одна и та же запись не создаёт второй звонок.
_Избегать_: вызов, запись (запись — это сам аудиофайл)

**Менеджер**:
Сторона разговора, представляющая компанию. Не путать с руководителем, который смотрит панель и правит оценки.
_Избегать_: оператор, продавец, агент

**Клиент**:
Вторая сторона разговора, с кем менеджер общается от имени компании.
_Избегать_: абонент, покупатель

**Реплика**:
Непрерывная речь одной стороны между репликами другой. Из реплик состоит расшифровка звонка.
_Избегать_: фраза, сегмент, высказывание

**Сторона / канал**:
Кто говорит: левый или правый канал стерео-записи. В моно сторона угадывается по паузам и поэтому условна.
_Избегать_: спикер, говорящий, дорожка

**Чек-лист**:
Упорядоченный список проверок, которым оценивается звонок; порядок повторяет этапы скрипта продаж.
_Избегать_: скрипт (скрипт — это сам сценарий продаж), анкета

**Пункт чек-листа**:
Одна проверка из чек-листа, например «выявил потребность». Имеет вес и может быть выполнен, провален или не применим.
_Избегать_: критерий, правило, шаг

**Выполнен / провален**:
Итог проверки пункта: у выполненного есть цитата-доказательство, у проваленного — причина и ближайшая цитата. Руководитель может заменить его ручной правкой.
_Избегать_: пройден, не пройден, ошибка

**«Не применим»**:
Статус условного пункта, когда повода для него не было (например, клиент не возражал). Такой пункт не влияет на балл.
_Избегать_: пропущен, не выполнен, н/д

**Возражение**:
Реплика клиента, выражающая сомнение или отказ («дорого», «подумаю»). Условный пункт проверяет, отработал ли его менеджер.
_Избегать_: жалоба, отказ

**Балл**:
Оценка звонка от 0 до 100: доля веса выполненных пунктов среди применимых, по действующей оценке. Делится на хороший, средний и плохой по порогам.
_Избегать_: рейтинг, оценка, процент

**Этап потери**:
Первый проваленный по действующей оценке пункт звонка по порядку чек-листа. Это вычисленная оценка, а не факт ухода клиента.
_Избегать_: причина отказа, точка отвала

**Общий вывод**:
Одна фраза вверху отчёта и обзора о том, на каком этапе компания теряет больше всего звонков.
_Избегать_: итог, резюме

**Расшифровка**:
Текст звонка с репликами сторон и временем. Бывает сырой (до назначения ролей) и размеченной ролями «Менеджер» / «Клиент».
_Избегать_: транскрипт, стенограмма

**«Стороны определены приблизительно»**:
Пометка звонка, записанного в моно: деление на менеджера и клиента угадано по паузам и менее надёжно.
_Избегать_: неточная запись

**«Не определён»**:
Имя менеджера, когда название файла не подошло под шаблон. Звонок всё равно анализируется; при смене шаблона имя пересчитывается.
_Избегать_: неизвестный, аноним

**Смысловая проверка**:
Необязательная перепроверка локальной языковой моделью: проваленных пунктов и условных пунктов, условие которых не нашлось по фразам (возражение своими словами). Вердикт принимается только с реальной цитатой нужной стороны.
_Избегать_: ИИ-проверка, нейроанализ

**Отчёт**:
Результат запуска консольной команды: HTML-страница для показа и Excel-файл с теми же данными, в новой папке с датой и временем. Панель отчётов не создаёт, там есть обзор и выгрузка в Excel.
_Избегать_: дашборд

**Панель**:
Веб-страницы руководителя, которые запускает команда `serve` или Docker: загрузка записей, обзор, менеджеры, звонки, настройки. Работает на офисном компьютере, под паролем.
_Избегать_: дашборд, сайт, веб-версия, админка

**Запись**:
Загруженный аудиофайл, ещё не обязательно разобранный. Одно содержимое — одна запись, даже под разными именами.
_Избегать_: файл, аудио, звонок (звонок — это уже результат разбора)

**Очередь**:
Записи, ожидающие разбора, обрабатываются по одной. У каждой статус: в очереди, обрабатывается, готово, ошибка. Пережидает перезапуск.
_Избегать_: задачи, список загрузок, пул

**Действующая оценка**:
Оценка пункта, которая считается в цифрах: ручная правка, если она есть, иначе автоматическая. Балл, этап потери, обзор, рейтинги и выгрузка строятся только по ней.
_Избегать_: итоговая оценка, финальный результат

**Ручная правка**:
Исправление оценки пункта или комментарий руководителя. Помечена «исправлено вручную», заменяет автоматическую оценку, отменяется и переживает переоценку.
_Избегать_: редактирование, override, коррекция

**Переоценка**:
Пересчёт оценок готовых звонков по текущему чек-листу без повторной расшифровки. Ручные правки сохраняются.
_Избегать_: перерасчёт, пересчёт, повторный анализ

**Период**:
Промежуток дат, за который панель показывает цифры: неделя, 4 недели, квартал, всё время или свои даты. Выбор помнится между страницами.
_Избегать_: диапазон, интервал

**Воронка**:
Пункты чек-листа по порядку: на каждом видно, сколько звонков его провалили и сколько на нём потеряно. Показывает, где скрипт проседает чаще всего.
_Избегать_: схема продаж, этапы продаж

**Папка данных**:
Место на компьютере, где панель хранит всё своё: базу, записи, рабочие настройки. Её копия — резервная копия панели.
_Избегать_: хранилище, каталог, база

**Рабочий чек-лист**:
Копия чек-листа, которую правит редактор панели и по которой оцениваются звонки. Встроенный чек-лист только даёт начальные значения.
_Избегать_: основной чек-лист, конфиг чек-листа

**Демо-база**:
Отдельная папка данных с выдуманными звонками для показа. Не смешивается с рабочей.
_Избегать_: тестовые данные, образец, примеры
