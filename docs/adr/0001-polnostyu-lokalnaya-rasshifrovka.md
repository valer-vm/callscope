## Контекст
Руководитель отдела продаж не хочет отдавать записи клиентов наружу, а облачная речевая аналитика для него дорогая. Нужна программа, которая работает на компьютере компании бесплатно.

## Решение
Расшифровка выполняется локально через faster-whisper на CPU, модель по умолчанию `small`, размер задаётся в конфиге и флагом. Единственный выход в сеть — разовое скачивание модели при первом запуске; можно указать локальный путь к уже скачанной модели. Других сетевых вызовов нет, кроме опционального Ollama на localhost.

## Почему
- Облачные API распознавания и готовые сервисы речевой аналитики отвергнуты: платные и отправляют записи наружу, то есть противоречат самой задаче.
- Модель побольше `small` по умолчанию не взята: программа рассчитана на обычный компьютер без GPU, а `small` на CPU обрабатывает минутный звонок примерно за 7 секунд.
- Требовать заранее положить модель вручную отвергнуто как неудобное для первого запуска; скачивание один раз проще, а путь к локальной модели закрывает закрытые сети.

## Последствия
- Первый запуск требует интернета и места под модель; в README и сообщении CLI это надо проговаривать.
- Точность распознавания ограничена размером модели: названия вроде «СтройДом» пишутся то «Строй дом», то «Стройдом», числа цифрами. Весь последующий разбор (поиск фраз, название компании) обязан это терпеть.
- Вернуться к облаку без пересмотра обещания «записи никуда не уходят» нельзя.
