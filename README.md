# CallScope — речевая аналитика звонков на своём компьютере

Руководитель отдела продаж не может прослушать сотни звонков, а сервисы речевой аналитики
дорогие и отправляют записи в облако. CallScope расшифровывает звонки и проверяет их
по скрипту продаж прямо на вашем компьютере или офисном сервере.

## Что это даёт

- **Видно, где теряются клиенты.** Каждый звонок получает балл по чек-листу скрипта,
  а обзор показывает, на каком этапе — приветствие, выявление потребности, возражение,
  следующий шаг — менеджеры проваливаются чаще всего.
- **Видно, кого учить и чему.** Рейтинг менеджеров, динамика по неделям и самый частый
  провал каждого — без прослушивания всех записей подряд.
- **Спорный звонок разбирается за минуту.** У каждого пункта — цитата из разговора, клик
  по ней перематывает запись; если программа ошиблась, оценку можно поправить вручную.
- **Записи не уходят из компании.** Расшифровка и проверка работают локально, без облака
  и абонентской платы; панель работает и без интернета.

## Как это устроено

Записи (mp3, wav, ogg, m4a) загружаются перетаскиванием в браузере. Речь распознаётся
моделью [faster-whisper](https://github.com/SYSTRAN/faster-whisper) на обычном процессоре,
стороны разговора — по каналам стерео-записи или по голосу. Проверка по чек-листу идёт
по ключевым фразам; по желанию пункты, которые не нашлись, перепроверяет локальная
нейросеть [Ollama](https://ollama.com) — она понимает, когда менеджер сказал нужное своими
словами. Для разовых разборов есть консольный отчёт в HTML и Excel.

## Попробовать

Демо-панель с вымышленной компанией и 150 звонками (нужен [uv](https://docs.astral.sh/uv/)):

```bash
git clone https://github.com/valer-vm/callscope.git && cd callscope && uv sync
```

```bash
cp .env.example .env    # впишите пароль в строку CALLSCOPE_PASSWORD
```

```bash
uv run callscope demo && uv run callscope serve --demo
```

Панель откроется по адресу <http://127.0.0.1:8000>.
